# 演示版部署说明：让家务打卡在 iPhone 上打开

这份说明给不写代码的人看，照着一步一步点就行。**电脑上不用装任何软件**，全部在网页上操作。

做完以后：

- 你们在 iPhone 上用自己的网址打开"家务打卡"，添加到主屏幕，用起来像一个 App；
- 以后每次我（云端开发）往 GitHub 推送新代码，Cloudflare 会自动更新网站，你什么都不用做。

> **演示版的限制**：数据只存在各自的手机上，两个人的手机之间**还不会同步**，也**不会推送提醒**。
> 这一版是用来确认界面和流程的。你确认没问题后，第 2 步会接上后台，两个人共用一份数据。

---

## 要准备的东西

| 东西 | 说明 |
|---|---|
| GitHub 账号 | 你已经有了，代码在 `github.com/xxsqka-blip/work_todo` |
| 一个邮箱 | 用来注册 Cloudflare |
| 一个域名 | 在阿里云或腾讯云买的，**并且已经通过实名认证**（没认证的域名解析不了） |
| 一台电脑 | 用浏览器操作 Cloudflare 和阿里云 / 腾讯云的网页，手机上点也可以，只是屏幕小 |

大概要花的时间：自己动手 20～30 分钟；"改 DNS 服务器"之后要等它生效，一般几分钟到几小时，最长一两天。

> Cloudflare 的网页有时会改版，按钮的名字可能和下面写的略有不同。下面同时写了中文和英文名称（括号里是英文），找不到就按意思找，或者截图发给我。

---

## 第 1 步：把演示版代码合并到 main

Cloudflare 默认从 `main` 分支部署，所以先把这次的代码合并进去。

1. 打开 `github.com/xxsqka-blip/work_todo`，点上面的 **Pull requests**。
2. 点开演示版那个 PR，先看看里面的截图。
3. 觉得可以就点绿色的 **Merge pull request**，再点 **Confirm merge**。

---

## 第 2 步：注册 Cloudflare

1. 打开 <https://dash.cloudflare.com/sign-up>，填邮箱和密码注册。
2. 去邮箱里点验证链接。
3. 选**免费计划（Free）**。不用绑银行卡。
4. 想看中文界面：点右上角的头像 →（Profile / 我的个人资料）→ 语言（Language）选"简体中文"。

---

## 第 3 步：连接 GitHub 仓库，自动部署

1. 在 Cloudflare 左边菜单点 **计算和 AI → Workers 和 Pages**（Compute & AI → Workers & Pages）。
   有的账号菜单里直接就是 **Workers 和 Pages**。
2. 点 **创建应用程序**（Create application）。
3. 选 **导入存储库 / 从 Git 导入**（Import a repository），再点 **连接 GitHub**（Continue with GitHub / Connect GitHub）。
4. 会跳到 GitHub 的授权页面：
   - 选你自己的账号 `xxsqka-blip`；
   - 选 **Only select repositories**（只授权选中的仓库），选 `work_todo`；
   - 点 **Install & Authorize**（安装并授权）。
5. 回到 Cloudflare，在仓库列表里选 `work_todo`。
6. 在设置页面填这几项（**其他保持默认，不用改**）：

   | 设置项 | 填什么 |
   |---|---|
   | 项目名称（Project name / Worker name） | `work-todo` |
   | 构建命令（Build command） | `npm run build` |
   | 部署命令（Deploy command） | `npx wrangler deploy` |
   | 根目录 / 路径（Root directory / Path） | 保持默认 `/` |
   | 生产分支（Production branch） | `main` |

   ⚠️ **项目名称必须是 `work-todo`**（中间是减号），要和仓库里 `wrangler.jsonc` 文件写的名字一样，不然会部署失败。

7. 点 **部署**（Deploy），等 1～3 分钟。看到成功（Success）就好了。
8. 页面上会出现一个 `work-todo.xxxx.workers.dev` 的网址。**这个网址在国内一般打不开，是正常的**，所以下面要绑自己的域名。

以后每次 `main` 分支有新代码，Cloudflare 会自动重新构建、部署。在 **Workers 和 Pages → work-todo → 部署**（Deployments）里能看到每一次的记录。

---

## 第 4 步：把域名交给 Cloudflare 管理

下面用 `example.com` 代替你的域名，操作时换成你自己的。

### 4.1 在 Cloudflare 上添加域名

1. 回到 Cloudflare 首页（左上角的 Cloudflare 图标），点 **添加域**（Add a domain / Onboard a domain）。
2. 输入你的域名，比如 `example.com`。**不要带 `www`，也不要带 `https://`**。
3. 如果问你"快速扫描 DNS 记录"之类的，保持默认，点 **继续**（Continue）。
4. 计划选 **Free（免费）**，继续。
5. 显示 DNS 记录的页面：新买的域名一般没有记录，直接 **继续**（Continue to activation）。
6. 页面会给你**两个 Cloudflare 域名服务器（Nameservers）**，长这样：

   ```text
   xxxx.ns.cloudflare.com
   yyyy.ns.cloudflare.com
   ```

   **每个账号给的不一样，以你页面上显示的为准**。把这两个复制下来，下一步要用。这个页面先别关。

### 4.2 在阿里云修改 DNS 服务器（在腾讯云买的看 4.3）

1. 登录 <https://dc.console.aliyun.com>（阿里云域名控制台）。
   也可以登录阿里云后，在顶部搜索"域名"进入"域名控制台"。
2. 左边点 **域名列表**，找到你的域名，点右边的 **管理**。
3. 左边点 **DNS 修改**（有的版本叫"DNS 服务器"）。
4. 点 **修改 DNS 服务器**，把原来的两个（一般是 `dns*.hichina.com`）删掉，换成 Cloudflare 给的两个。
5. 点 **确定**，可能要手机验证码。
6. 如果页面上有 **DNSSEC** 并且是开着的，先关掉（新买的域名一般默认是关的）。

### 4.3 在腾讯云修改 DNS 服务器

1. 登录 <https://console.cloud.tencent.com/domain>（腾讯云"我的域名"）。
2. 找到你的域名，点右边的 **管理**。
3. 在"DNS 服务器"那一栏点 **修改**。
4. 选 **自定义 DNS**，删掉原来的（一般是 `*.dnspod.net`），填上 Cloudflare 给的两个。
5. 点 **提交**。
6. 如果开着 **DNSSEC**，先关掉。

### 4.4 等它生效

1. 回到 Cloudflare 刚才那个页面，点 **检查域名服务器**（Check nameservers）。
2. 生效时间一般几分钟到几小时，最长 24～48 小时。生效后 Cloudflare 会发邮件给你，域名状态会变成 **活动**（Active）。
3. 没生效之前，下一步会添加不了，或者网址打不开，耐心等等。

---

## 第 5 步：把域名绑到网站上

建议用一个**子域名**，比如 `jiawu.example.com`（"家务"的拼音），主域名以后还能干别的。直接用 `example.com` 也可以。

1. Cloudflare 左边菜单 **Workers 和 Pages** → 点 **work-todo**。
2. 点 **设置**（Settings）→ 找到 **域和路由**（Domains & Routes）→ 点 **添加**（Add）。
3. 选 **自定义域**（Custom domain）。
4. 输入 `jiawu.example.com`（换成你的域名），点 **添加域**（Add domain）。
5. Cloudflare 会自动配置好解析和 HTTPS 证书，等几分钟。
6. 在电脑或手机浏览器打开 `https://jiawu.example.com`，能看到"家务打卡"就成功了 🎉

> 以后自动部署**不会**改动这个绑定，绑一次就行。
> 方便的话把最终的网址告诉我，后面写说明的时候直接用。

## 第 6 步：在 iPhone 上打开、添加到主屏幕

两个人的 iPhone 都这样做一遍。

1. 用 **Safari**（系统自带的浏览器）打开 `https://jiawu.example.com`。
   **不要在微信里打开**：微信里的网页没法添加到主屏幕。可以把网址复制到 Safari 里打开。
2. 点 **分享** 按钮（一个方框，上面有向上的箭头）：
   - iOS 26：先点地址栏旁边的 **"⋯"**，再点 **分享**；
   - iOS 18 及更早：分享按钮在屏幕最下面一排中间。
3. 在弹出的菜单里往下滑，点 **添加到主屏幕**。
   如果没看到，往下滑到最底部点"编辑操作…"，把"添加到主屏幕"加进来。
4. 名称保持"家务打卡"。如果有 **"作为 Web App 打开"** 的开关，保持**打开**。点右上角 **添加**。
5. 回到主屏幕，点"家务打卡"图标打开。**全屏显示、看不到地址栏**，就说明装好了。

几点说明：

- **以后都从主屏幕图标打开**。主屏幕上的 App 和 Safari 里的数据是分开存的：在 Safari 里试着打过的卡，在主屏幕 App 里看不到，这是 iPhone 的规定，正常现象。
- **演示版两个人的数据不同步**。想试"两个人轮流打卡"，可以在一台手机上点顶部的"我是 我 / TA"切换身份。
- **没网也能打开**：添加到主屏幕、打开过一次以后，没网也能用（演示版的数据本来就存在手机上）。
- **怎么更新到新版本**：我推送新代码后，Cloudflare 几分钟内会自动部署。手机上把"家务打卡"从后台划掉、重新打开一两次，就是新版本了。
- 提醒推送要 **iOS 16.4 以上**，这一版还没有，第 3 步才接上。可以先在"设置 → 通用 → 关于本机"看看 iOS 版本。

## 遇到问题

| 现象 | 怎么办 |
|---|---|
| Cloudflare 部署失败（Failed） | 在 **work-todo → 部署**（Deployments）里点开失败的那次，看"构建日志"（Build log），截图发给我 |
| 日志里说名字不对（name mismatch 之类） | 项目名称必须是 `work-todo`，和 `wrangler.jsonc` 里的一致 |
| `xxx.workers.dev` 打不开 | 正常，国内一般打不开，用自己的域名 |
| 自己的域名打不开 | ① 域名是否已经实名认证；② Cloudflare 里域名状态是不是"活动"（Active）；③ 刚改完 DNS 服务器要等一等；④ 换成手机流量试试 |
| 添加到主屏幕后打开还有地址栏 | 删掉主屏幕图标，确认是用 Safari 打开的，再按第 6 步重新添加 |
| 页面没变成新版本 | 从后台划掉 App，重新打开一两次 |

有任何一步卡住，把那一步的页面截图发给我就行。
